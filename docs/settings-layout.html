How this stays simple

  • Path tiles are short: name + four words. The sheet does not scroll.
  • Star pins. You cannot pin more than 3, so Home stays a row of chips, not a second Settings.
  • Home chips open the same one-path sheet. Change Last-minute without walking Settings → Paths → scroll.
  • No pin = Home shows a one-line hint, then nothing extra. Last signals stays the main list.
  • Shared limits can be pinned too, or left only in the Paths sheet.
