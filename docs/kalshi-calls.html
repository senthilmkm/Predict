Cloud Run · Kalshi production API

What we call, why, and how often.

Live trading is Cloud. The phone Last signals card reads Cloud every 1s for asks and gap. Cushions-On coins only for lean and the quotes WebSocket. Empty Cushions list means no lean calls. Admin Tick interval (usually 10s) is user walk + ticker reconcile — not a 1s REST flood.

Lean (gap)

Once per second per On coin: Kalshi live_data. Full /events only on miss or window end.

Ask / bid

One quotes WebSocket, orderbook_delta, Cushions-On tickers. Pump every 1s; book updates as Kalshi pushes.

Orders

Signed POST /portfolio/events/orders only when a path or Home Buy actually places. Then short fill confirm.

Not Kalshi

Pyth Hermes is a spot fallback if live_data is empty. CF Benchmarks is the TWAP official index (or Kalshi proxy).
