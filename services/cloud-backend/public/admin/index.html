🛠️ Developer & GCP Infrastructure Guide predict-cloud-api

Complete reference manual for administrators and developers managing Predict GCP Cloud Infrastructure.

1. GCP Project & Endpoints

GCP Project ID: predict-cloud-api-428463178740
GCP Region: us-east1
Cloud Run Service URL: https://predict-cloud-api-428463178740.us-east1.run.app
Admin Portal URL: https://predict-cloud-api-428463178740.us-east1.run.app/admin

2. Deploy Backend Commands

To build and deploy updates to GCP Cloud Run:

cd services/cloud-backend
gcloud run deploy predict-cloud-api --source . --region us-east1 --allow-unauthenticated

3. Cloud Firestore Database Schema

  • • users/{userId}: User status doc (`cloudTradingEnabled`, `state: ARMED/DISARMED`, `config`, `pushTokens`).
  • • users/{userId}/trades/{tradeId}: Individual execution trade records (`status: SUBMITTED/FILLED`, `notionalUsd`, `price`, `count`).
  • • users/{userId}/audit/{logId}: Audit trail (`KEY_UPLOAD`, `KILL_SWITCH`, `TRADE_TRIGGERED`, `ERROR`).

4. Race-Condition Protections

State updates execute atomically in Firestore using merge operations. The 20s worker tick loop enforces an in-flight execution lock (`tickInFlight`) so overlapping invocations cannot trigger double order placement.
